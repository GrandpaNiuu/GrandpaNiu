# Scripts

本目录用于放置脚本源文件或脚本来源说明。

当前仓库的实际脚本大多仍通过 `Ronghemokuai.sgmodule` 中的 `script-path=` 引用远程上游。

建议后续拆分：

```text
spotify.md      Spotify 脚本来源和维护说明
youtube.md      YouTube Enhance 来源和维护说明
app-clean.md    常用 App 净化脚本来源说明
```

维护原则：

- 不保存未知混淆脚本。
- 不加入破解、解锁、支付绕过、登录绕过脚本。
- Spotify / YouTube 脚本为重点保护项，不自动删除。
- 远程脚本失效时先进入报告，再人工确认替换。
