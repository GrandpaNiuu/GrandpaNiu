# Rewrite Registry

This is the master source index for the module factory. It links editable sources, generated outputs, generator scripts, risk level, and fallback path.

## Registry model

| Field | Meaning |
|---|---|
| ID | Stable registry identifier |
| Layer | Factory layer: source, remote, build, release, web, legacy |
| Type | Source/output category |
| Source path | Editable input or registry source |
| Output path | Generated output or public artifact |
| Generated by | Builder or script responsible for output |
| Enabled | Whether it is part of the current production path |
| Risk | Operational risk if changed |
| Fallback | Recovery path |

## Operating rules

- Edit source files first; do not treat `Release/` as source of truth.
- Every high-risk source must have a fallback path.
- App-specific source fragments live under `Rewrite/Sources/Apps/` and generate `Release/Modules/*.sgmodule`.
- Reference modules in `Rewrite/Remotes/sources.json` are disabled by default and are not public import entries.
- `Web/catalog.md` and `Web/release-links.json` are public catalog outputs; legacy variants must stay out of the catalog.
- If a generated output is wrong, revert the source/config/script that produced it, then rerun `Rewrite/Generator/Builder.py --profile fusion --release`.
