## Build behavior

`Release/Modules/*.sgmodule` is generated by `scripts/build_release_modules.py`.

For each app listed in `Rewrite/Generate.conf` `[release_modules]`:

1. If `Rewrite/Sources/Apps/<slug>.conf` exists, that file is used as the app module source.
2. If the app source file does not exist, the builder falls back to extracting matching lines from `Release/Ronghemokuai.sgmodule`.
3. Empty modules are skipped unless `include_empty_modules = true` is set in `Rewrite/Generate.conf`.

## Maintenance rule

Edit app-specific rules here first. Do not edit generated files under `Release/Modules/` as the source of truth.
