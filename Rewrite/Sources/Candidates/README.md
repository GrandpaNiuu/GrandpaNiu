# Candidate Rewrite Sources

This folder is the holding area for rules, rewrite fragments and script ideas that may be useful for the single public fusion module but are not ready to enter `Rewrite/Sources/Apps/` or `Rewrite/Sources/Misc/`.

Candidate material must include:

- source URL or upstream project name
- intended App or service
- expected benefit
- risk level: `low`, `medium`, `high`, or `critical`
- reason it is not yet merged into the fusion module
- rollback note

Rules here are not part of the public `Ronghemokuai.sgmodule` build until they are promoted into the normal source folders and registered in the generator plan when needed.
