# Rejected Rewrite Sources

This folder records material that was reviewed and intentionally kept out of the single public fusion module.

Use this folder for snippets that are:

- too broad
- duplicate with existing fusion sources
- missing traceable source information
- tied to abandoned upstream rules
- not suitable for the current fusion policy

Do not delete rejected material without a note in `Rewrite/Registry.md` or a maintenance report. The goal is to avoid re-importing the same risky source later.
