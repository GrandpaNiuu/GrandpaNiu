GrandpaNiu Android 导入页

Android 版本支持 Mihomo / Clash Meta / FlClash 等客户端。由于安卓客户端不一定支持同一个跳转协议，如果一键导入失败，请复制链接后在客户端中手动导入。

没有节点，只想做广告拦截

请导入 GrandpaNiu-Android-Full.yaml。这个文件是完整 Mihomo 配置，适合没有节点、只想做广告拦截的用户。

配置链接： https://raw.githubusercontent.com/GrandpaNiuu/GrandpaNiu/main/Android/mihomo/GrandpaNiu-Android-Full.yaml
一键尝试导入 查看教程
如果点击无反应，说明当前安卓客户端不支持该跳转协议，请复制链接后手动导入。

已有节点订阅用户

不要导入 GrandpaNiu-Android-Full.yaml。GrandpaNiu-Android-Full.yaml 可能会覆盖你的原节点、策略组和规则。

已有节点用户应使用 GrandpaNiu-Ads.yaml 作为 rule-provider，把它加入自己原来的 Clash / Mihomo 配置里。

规则集链接： https://raw.githubusercontent.com/GrandpaNiuu/GrandpaNiu/main/Android/mihomo/GrandpaNiu-Ads.yaml
查看已有节点用户教程

已有节点用户核心示例

把下面的 rule-provider 加入原配置，并把 GrandpaNiu 广告规则放在 rules 最前面。

rule-providers:
  grandpaniu_ads:
    type: http
    behavior: classical
    format: yaml
    url: "https://raw.githubusercontent.com/GrandpaNiuu/GrandpaNiu/main/Android/mihomo/GrandpaNiu-Ads.yaml"
    path: ./ruleset/GrandpaNiu-Ads.yaml
    interval: 86400

rules:
  - RULE-SET,grandpaniu_ads,REJECT
  - MATCH,🚀 节点选择
RULE-SET,grandpaniu_ads,REJECT 必须放在 MATCH、GEOIP、代理分流规则之前。

保留原来的节点、策略组和 MATCH。广告请求拦截，其他流量继续走原节点。

v2rayNG / V2Ray / Xray 高级用户方案

这是高级用户方案，不作为普通用户主推。普通用户推荐优先使用 FlClash / Mihomo。

v2rayNG 不能直接导入 GrandpaNiu-Ads.yaml；它是 Mihomo / Clash 规则集，不是 V2Ray 配置。v2rayNG 用户应使用 routing JSON 片段，并手动合并到自己原来的配置里。

routing 片段链接： https://raw.githubusercontent.com/GrandpaNiuu/GrandpaNiu/main/Android/v2rayng/GrandpaNiu-v2rayng-routing.json
查看 v2rayNG 手动合并教程
不要把 v2rayNG 方案当成一键完美导入。已有节点用户应保留原来的 outbounds，把 block outbound 和广告 routing.rules 合并进原配置。

广告 routing.rules 必须放在普通 proxy/direct 规则之前。广告命中 block，其他流量继续走原节点。

GrandpaNiu Android 版本只迁移域名、关键词、IP 规则，不迁移 iOS / Surge / Shadowrocket 的 Script、MITM、Rewrite、Header Rewrite、Body Rewrite 功能。
