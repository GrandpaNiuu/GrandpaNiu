GrandpaNiu · Android Rules

Android 单一入口

普通用户只导入下面这一个主规则集。它已经聚合 Android 原生规则、iOS 通用兼容层和 iOS App 兼容增强层，尽量像 iOS Fusion 一样保持一个公开入口。

Android 客户端格式不统一，所以仓库底层仍会生成多种兼容文件；但公开导入页只主推一个入口，其他文件仅保留给高级用户排查。

唯一推荐入口

GrandpaNiu Android 主规则集

适合 Mihomo、Clash Meta、FlClash 等支持 rule-provider 的客户端。这个入口不会覆盖你的节点订阅和策略组，只把净化规则作为远程规则集加入现有配置。

推荐 单一入口 已聚合 iOS 兼容层 不会覆盖节点
https://grandpaniuu.github.io/GrandpaNiu/Android/mihomo/GrandpaNiu-Ads.yaml
不要再额外重复导入 iOS-Compatible-Reject 或 iOS-App-Compatible-Reject。它们已经进入主规则集，重复启用只会增加排查难度。

接入方式

Mihomo / Clash Meta / FlClash 配置片段 
rule-providers:
  grandpaniu_ads:
    type: http
    behavior: classical
    format: yaml
    url: "https://grandpaniuu.github.io/GrandpaNiu/Android/mihomo/GrandpaNiu-Ads.yaml"
    path: ./ruleset/GrandpaNiu-Ads.yaml
    interval: 86400

rules:
  - RULE-SET,grandpaniu_ads,REJECT
  - MATCH,节点选择
规则必须放在 MATCH、GEOIP 和普通代理分流规则之前。Android Clash Meta / Clash Mi 如果开启了“分应用代理”，部分 App 可能不会经过规则，请优先关闭分应用代理后测试。

边界说明

Android 版只迁移域名、关键词、IP、DNS 和 routing 规则，不包含 iOS / Surge / Shadowrocket 的 Script、MITM、URL Rewrite、Header Rewrite、Body Rewrite 能力。登录、支付、银行、验证码、视频播放、图片 CDN 保护链路不会被迁移成 Android 拦截规则。

如果你只想“像 iOS 一样一个入口”，就只使用本页的主规则集。其他文件存在是为了兼容不同 Android 客户端和维护排查，不是给普通用户逐个导入的版本线。
导入失败时，请复制主入口链接，在客户端中选择“从 URL 导入规则集”或按配置片段手动合并。
