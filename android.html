GrandpaNiu Android 导入页

Android 版本支持 Mihomo / Clash Meta / FlClash 等客户端。由于 Android 客户端不一定支持同一个跳转协议，如果一键导入失败，请复制链接后在客户端中手动导入。

没有节点，只想做广告拦截

请导入 GrandpaNiu-Android-Full.yaml。这个文件是完整 Mihomo 配置，适合没有节点、只想做广告拦截的用户。

完整配置链接：

https://raw.githubusercontent.com/GrandpaNiuu/GrandpaNiu/main/Android/mihomo/GrandpaNiu-Android-Full.yaml
一键尝试导入 查看教程

如果点击无反应，说明当前安卓客户端不支持该跳转协议，请复制链接后手动导入。

已有节点订阅用户

不要导入 GrandpaNiu-Android-Full.yaml。

GrandpaNiu-Android-Full.yaml 可能会覆盖你的原节点、策略组和规则。

已有节点用户应使用 GrandpaNiu-Ads.yaml 作为 rule-provider，把它加入自己原来的 Clash / Mihomo 配置里。

规则集链接：

https://raw.githubusercontent.com/GrandpaNiuu/GrandpaNiu/main/Android/mihomo/GrandpaNiu-Ads.yaml
查看已有节点用户教程

已有节点用户核心示例

rule-providers:
  grandpaniu_ads:
    type: http
    behavior: classical
    format: yaml
    url: "https://raw.githubusercontent.com/GrandpaNiuu/GrandpaNiu/main/Android/mihomo/GrandpaNiu-Ads.yaml"
    path: ./ruleset/GrandpaNiu-Ads.yaml
    interval: 86400

rules:
  - RULE-SET,grandpaniu_ads,REJECT
  - MATCH,🚀 节点选择

RULE-SET,grandpaniu_ads,REJECT 必须放在 MATCH、GEOIP、代理分流规则之前。

保留原来的节点、策略组和 MATCH。广告请求拦截，其他流量继续走原节点。
