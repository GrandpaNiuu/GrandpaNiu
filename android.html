1. 完整配置版

无节点用户MihomoFlClashClash Meta

适合没有机场节点、没有现成配置、只想做广告拦截的用户。这个文件可以作为完整配置导入。

已有节点订阅用户不要导入这个版本，否则可能覆盖原节点、策略组和规则。
配置链接： https://raw.githubusercontent.com/GrandpaNiuu/GrandpaNiu/main/Android/mihomo/GrandpaNiu-Android-Full.yaml
一键尝试导入
完整配置版怎么导入
  1. 打开 FlClash / Mihomo / Clash Meta。
  2. 进入「配置 / Profiles」。
  3. 选择「从 URL 导入」。
  4. 粘贴完整配置链接。
  5. 保存并启用该配置。

2. Mihomo 规则集版

已有节点用户rule-provider不覆盖节点

适合已经有机场节点订阅的用户。把 GrandpaNiu 作为远程规则集加入原配置，不要覆盖原节点。

规则集链接： https://raw.githubusercontent.com/GrandpaNiuu/GrandpaNiu/main/Android/mihomo/GrandpaNiu-Ads.yaml
查看已有节点用户教程
Mihomo 规则集怎么合并

把下面内容加入原配置，并放在普通代理规则和 MATCH 前面。

rule-providers:
  grandpaniu_ads:
    type: http
    behavior: classical
    format: yaml
    url: "https://raw.githubusercontent.com/GrandpaNiuu/GrandpaNiu/main/Android/mihomo/GrandpaNiu-Ads.yaml"
    path: ./ruleset/GrandpaNiu-Ads.yaml
    interval: 86400

rules:
  - RULE-SET,grandpaniu_ads,REJECT
  - MATCH,🚀 节点选择
RULE-SET,grandpaniu_ads,REJECT 必须放在 MATCH、GEOIP、代理分流规则之前。

3. sing-box 规则集版

sing-boxSFA高级用户

适合会维护 sing-box 配置的用户。它是 rule-set 文件，不是完整 sing-box 配置。

rule-set 链接： https://raw.githubusercontent.com/GrandpaNiuu/GrandpaNiu/main/Android/sing-box/GrandpaNiu-Ads.json
sing-box 怎么使用
  1. 打开自己的 sing-box 配置。
  2. 在 rule-set 区域添加远程规则集地址。
  3. 在 route.rules 中引用 GrandpaNiu 规则集。
  4. 命中后走拦截动作。
  5. 保存配置并重载客户端。
不会改 sing-box JSON 的用户，优先使用 Mihomo / FlClash 方案。

4. AdGuard DNS 规则版

AdGuardDNS 过滤轻量

适合 AdGuard Android、AdGuard DNS 或 AdGuard Home 的自定义过滤规则场景。只能做域名级拦截。

DNS 规则链接： https://raw.githubusercontent.com/GrandpaNiuu/GrandpaNiu/main/Android/adguard/GrandpaNiu-DNS.txt
AdGuard 怎么导入
  1. 打开 AdGuard Android、AdGuard DNS 或 AdGuard Home。
  2. 进入「过滤器 / 用户规则 / DNS 过滤」相关页面。
  3. 添加自定义规则或订阅。
  4. 粘贴 DNS 规则链接。
  5. 保存并刷新规则。
这是域名级过滤，不包含 Script、MITM、Rewrite。

5. v2rayNG routing 片段版

v2rayNGV2RayXray手动合并

适合已经会手动改 V2Ray / Xray 配置的高级用户。它不是节点订阅，也不是完整配置。

routing 片段链接： https://raw.githubusercontent.com/GrandpaNiuu/GrandpaNiu/main/Android/v2rayng/GrandpaNiu-v2rayng-routing.json
查看 v2rayNG 手动合并教程
v2rayNG / V2Ray / Xray 怎么合并
  1. 打开你现有的配置文件。
  2. 找到 routing.rules。
  3. 把 GrandpaNiu 的广告 routing 片段手动合并进去。
  4. 确保广告拦截规则排在普通代理 / 直连规则之前。
  5. 保存并重新加载配置。
不能直接当节点订阅导入。不会手动改 routing 的用户，优先使用 Mihomo / FlClash。

6. 新手推荐顺序

新手优先看排错
  1. 没有节点：用完整配置版。
  2. 已有节点：用 Mihomo 规则集版。
  3. 完全不懂配置：优先用 FlClash / Mihomo。
  4. 只想轻量过滤：用 AdGuard DNS 规则版。
  5. 会手动改配置：再考虑 sing-box 或 v2rayNG。

Android 使用边界

Android 版只迁移域名、关键词、IP 规则和部分可迁移拦截逻辑。

Android 版不包含 iOS / Surge / Shadowrocket 的 Script、MITM、Rewrite、Header Rewrite、Body Rewrite 能力，所以不保证达到 iOS 模块完全相同的净化效果。

如果一键导入失败，请复制对应链接，在客户端中选择「从 URL 导入」或按对应教程手动合并。
