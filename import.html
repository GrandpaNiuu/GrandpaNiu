融合模块

面向 Shadowrocket / Surge / Android 的广告净化规则集合。普通用户只需要安装一个 Fusion 模块。

iOS Fusion 模块

推荐入口：适用于 Shadowrocket / Surge。融合常见 App 净化规则、脚本、Rewrite 与 MITM 覆盖，支持在模块内使用 编辑参数 调整部分功能。

↪ 安装模块 ▰ 模块文件 复制链接

安装前建议停用旧模块，不要把旧 Stable / Stable Plus / Lite / Full 与 Fusion 同时启用。

https://grandpaniuu.github.io/GrandpaNiu/Ronghemokuai.sgmodule

Android 规则

Android 用户：根据自己的客户端选择规则格式。适合 Mihomo、Clash Meta、FlClash、sing-box、AdGuard DNS、AdGuard Home、v2rayNG / V2Ray / Xray 等场景。

▰ Android 导入页 Release 目录

Android 规则主要是域名、IP、DNS 和分流规则，不能完全等同 iOS 的 Script、MITM、Rewrite 效果。

仓库报告

维护者入口：查看仓库健康、构建产物和规则覆盖情况。普通用户遇到异常时，优先关闭模块或对应 App 增强规则排查。
