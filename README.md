## 📱 使用说明

1. 确保 iPhone 已安装 Shadowrocket
2. 点击上方“打开导入页面”
3. 在 Safari 中点击“一键导入 Shadowrocket 模块”
4. 跳转到 Shadowrocket 后确认添加模块
5. 在模块列表中启用即可
