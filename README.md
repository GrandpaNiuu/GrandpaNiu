## 📱 使用说明

1. 确保 iPhone 已安装 Shadowrocket
2. 推荐在 Safari 或 GitHub App 中点击“安装模块”按钮
3. 跳转到 Shadowrocket 后确认添加模块
4. 在模块列表中启用即可
5. 如果没有自动跳转，请打开备用页面后复制模块地址手动导入
