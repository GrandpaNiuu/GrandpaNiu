# 项目范围说明

本仓库用于维护 Shadowrocket / Surge 自用融合净化模块，目标是稳定、可回滚、可排查、可自动构建的广告净化和远程规则安全维护。

## 本仓库只做

- 广告拦截
- 开屏广告处理
- 弹窗清理
- 横幅清理
- 信息流净化
- 推荐位清理
- 活动卡片清理
- 网页广告净化
- YouTube Enhance 保留
- Spotify 播放保护
- 知乎广告卡片净化
- Bilibili 局部净化
- 国内 App 常见广告净化
- 远程规则和脚本的安全维护
- 源头驱动模块构建
- 失效源审计与保守修复
- 性能与低耗电 profile 维护

## 本仓库不做

- 会员解锁
- Premium 破解
- 支付绕过
- 登录绕过
- 账户权益伪造
- 证书绕过
- Cookie 签到任务
- BoxJS 账号任务
- 成人内容
- 博彩内容
- 灰产内容
- 短链脚本
- 未知混淆脚本
- ghproxy / mirror 正式源
- 来源不可验证脚本
- 大面积 MITM 扩张
- 账号状态、token、cookie、付费状态改写

## 自动维护边界

- 单日失败只记录报告，不自动处理。
- 连续 2 天确认失效后，优先同源替换，其次注释，最后才允许低风险独立远程规则删除。
- Spotify、YouTube、知乎增强、主模块地址、安装 / 导入页面和核心远程规则源只报告，不自动注释、删除或替换。
- 无法确认安全性的内容只写入报告，等待后续确认。
- 候选源收集以 `Rewrite/Remotes/candidates.json` 为准，不建议直接全网乱搜。
- 脚本默认 pending，不直接加入 stable。

## 风险优先级

最高风险：

```text
登录
支付
验证码
银行
微信
支付宝
账号身份
Cookie / Token
付费内容
会员权益
```

这些对象默认不拦截、不改写。确需处理广告时，只能做极小范围、可回滚、可测试的局部规则。
