# 项目范围说明

本仓库用于维护 Shadowrocket 自用综合模块，目标是稳定、可回滚、可排查的广告净化和远程规则安全维护。

## 本仓库只做

- 广告拦截
- 开屏广告处理
- 弹窗清理
- 横幅清理
- 信息流净化
- 推荐位清理
- 活动卡片清理
- YouTube 增强
- Spotify 处理
- 国内 App 净化
- 远程规则和脚本的安全维护

## 本仓库不做

- 会员破解
- Premium 解锁
- 支付绕过
- 登录绕过
- 账户权益伪造
- 证书绕过
- Cookie 签到任务
- BoxJS 账号任务
- 成人内容
- 博彩内容
- 灰产内容
- 短链脚本
- 未知混淆脚本

## 自动维护边界

- 单日失败只记录报告，不自动处理。
- 连续 2 天确认失效后，优先同源替换，其次注释，最后才允许低风险独立远程规则删除。
- Spotify、YouTube、主模块地址、安装 / 导入页面和核心远程规则源只报告，不自动注释、删除或替换。
- 无法确认安全性的内容只写入报告，等待人工确认。
